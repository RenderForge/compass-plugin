# Compass plugin for Claude Code

Compass for Claude Code: the project's working rules, as a skill.

You do not install this by hand: the Compass setup command does it. In your project folder run

    curl -fsSL <your-compass>/setup.sh | sh        # macOS / Linux
    irm <your-compass>/setup.ps1 | iex             # Windows

Generated by `scripts/build_plugin.py` in the Compass repo from `compass/agent_rules.py` — do not edit these files here; change the rules in Compass and rebuild.
