# Compass plugin for Claude Code

Compass for Claude Code: the project's working rules, as a skill, and a commit check that keeps every commit linked to its task.

You do not install this by hand: the Compass setup command does it. In your project folder run

    curl -fsSL <your-compass>/setup.sh | sh        # macOS / Linux
    irm <your-compass>/setup.ps1 | iex             # Windows

To install it by hand (the same line works in a Unix shell and in PowerShell):

    claude plugin marketplace add RenderForge/compass-plugin; claude plugin install compass@compass

The first command matters: `claude plugin install` does not add a marketplace that is only named in a project's `.claude/settings.json`. Claude Code needs `git` to download it. If a marketplace called `compass` already points somewhere else, `claude plugin marketplace remove compass` first — but removing a marketplace also removes the plugins installed from it, so only do that if it is not one you want to keep.
